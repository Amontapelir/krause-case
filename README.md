# Krause.pro — Telegram Mini App онлайн-курсов

> Коммерческий проект для автора курсов о детско-родительских отношениях.
> Код закрыт по договорённости с заказчиком, здесь — описание решения.

**Роль:** единственный разработчик — backend, фронтенд мини-аппа, бот, деплой и поддержка.

<!-- Скриншоты: разбор в чате, урок, админка (согласовать с заказчиком) -->

## Что умеет
- Вход только через Telegram: регистрации нет, личность подтверждает подпись Telegram (`initData`).
- Бесплатный шаг: видео, разбор ситуации в чате с ИИ (GigaChat), два урока с упражнениями.
- Платный курс с личным кабинетом, оплата через Т-Кассу, доступ выдаётся одной транзакцией.
- Админка для заказчика: рассылки текстом и видеокружками, аналитика, права доступа, управление уроками.

## Стек
Python, FastAPI, SQLite, Telegram Bot API, GigaChat API, Т-Касса, Яндекс Object Storage, Linux VPS, systemd.

## Качество и надёжность
- 231 автотест (unittest).
- После ревью исправлены 9 ошибок надёжности: падение бота на не-JSON ответе Telegram,
  потеря сообщений при сбое сети, зависшее автосписание и другие.
- 278 пользователей в базе на 14.10.2026.

## Что было сложно
- **Админка.** Заказчик не программист, поэтому всё управление курсом пришлось вынести в интерфейс: уроки, права доступа, аналитику и рассылки текстом и видеокружками. Рассылка сначала уходит администраторам и только после их подтверждения — всем пользователям.
